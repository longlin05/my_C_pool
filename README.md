# Memory Pool

C 语言实现的固定大小内存池，专为嵌入式系统和性能敏感场景设计。

## 特性

- **固定大小块**：预分配的统一大小内存块
- **多页管理**：内存不足时自动扩展新页
- **零分配分配**：从空闲链表直接返回预分配块
- **内存对齐**：支持可配置的对齐要求（默认 4 字节对齐）
- **提前建页**：在内存耗尽前主动创建新页
- **嵌入式友好**：无外部依赖，符合 C 语言最佳实践

## 架构

├─────────────────────────────────────────────────────────┤

│ align                 │ raw_ptr: malloc 返回地址 │      │

│                       │ end:    页结束地址       │      │
│                       │ free:   剩余可用大小     │      │

│                       └─────────────────────────┘       │
│                                                   ┌─────▼─────┐
│  mem_block (空闲链表)                             │  mem_page │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ├───────────┤
│  │  next ───┼──▶ │  next ───┼──▶ │  next ───┼──▶ │   ...   │

## 配置

在 `main.c` 中修改以下宏来定制内存池：

| 宏                     | 默认值  | 说明           |
| --------------------- | ---- | ------------ |
| `BLOCK_SIZE`          | 64   | 每个内存块的大小（字节） |
| `PAGE_SIZE`           | 4096 | 每个页的大小（字节）   |
| `MEM_POOL_ALIGN_SIZE` | 4    | 内存对齐要求       |

### 计算

- 每页块数：`PAGE_SIZE / BLOCK_SIZE` = 4096 / 64 = **64 块**
- 建页触发条件：剩余空间 ≤ **2 块**

## API 参考

### 初始化内存池

```c
mem_pool_t* mem_pool_init(void);
```

创建并初始化内存池。失败返回 `NULL`。

**注意**：第一页在初始化时创建。

***

### 分配内存块

```c
void* mem_pool_alloc(mem_pool_t *pool);
```

从池中分配一个块。满足以下条件时返回 `NULL`：

- `pool` 为 `NULL`
- 无法分配新页（内存不足）

满足以下条件时自动创建新页：

- `free_list` 为空
- 当前页剩余空间 ≤ 2 块
- 重新建新页时舍弃旧页最后剩下的一两块地址

***

### 释放内存块

```c
void mem_pool_free(mem_pool_t *pool, void *ptr);
```

将块归还到空闲链表。传入 `NULL` 指针安全。

***

### 销毁内存池

```c
void mem_pool_destroy(mem_pool_t *pool);
```

释放所有页和池结构体。传入 `NULL` 安全。

## 使用示例

```c
#include "pool.h"

int main(void) {
    // 初始化内存池
    mem_pool_t *pool = mem_pool_init();
    if (pool == NULL) {
        return -1;
    }

    // 分配内存块
    void *ptr1 = mem_pool_alloc(pool);
    void *ptr2 = mem_pool_alloc(pool);

    // 使用内存
    strcpy(ptr1, "Hello");
    printf("块1: %s\n", (char*)ptr1);

    // 释放块（归还到空闲链表）
    mem_pool_free(pool, ptr1);

    // 重新分配（获得刚才释放的块）
    void *ptr3 = mem_pool_alloc(pool);
    printf("块3: %s\n", (char*)ptr3);

    // 清理
    mem_pool_destroy(pool);
    return 0;
}
```

## 内存布局

```
页内存 (malloc 分配):
┌─────────────────────────────────────┐
│ raw_ptr (malloc 返回地址)           │
├─────────────────────────────────────┤
│ [padding] ──▶ aligned_addr (start) │
├─────────────────────────────────────┤
│                                     │
│         可用空间                    │
│         BLOCK_SIZE × N              │
│                                     │
├─────────────────────────────────────┤
│ end = raw_ptr + PAGE_SIZE           │
└─────────────────────────────────────┘
```

**对齐处理**：

- 开头最多浪费 `(align - 1)` 字节
- `free` 空间会扣除这个开销
- 只有原始的 `raw_ptr` 会传给 `free()`

## 线程安全

**非线程安全**。多线程环境下需要在所有池操作外加同步机制（互斥锁、自旋锁等）。

## 错误处理

- 所有函数检查 `NULL` 参数
- 优雅处理 `malloc` 失败
- 错误路径无内存泄漏
- `free()` 始终使用原始 `malloc` 返回值

## 可移植性

- 兼容 C89/C99 标准
- 无外部依赖（仅使用 `stdlib.h`、`stdint.h`）
- 支持平台：Linux、Windows、macOS、嵌入式系统
